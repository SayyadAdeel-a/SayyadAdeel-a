### 🧮 How levels and language ranks are calculated

No manually inflated numbers. The goal is to make the stats traceable to GitHub data.

**Level & XP**

A custom scoring system based on GitHub activity:

| Activity | XP |
|---|---:|
| Contributions | 1 XP |
| Commits | 1 XP |
| Pull requests | 5 XP |
| Stars received | 5 XP |
| Public repositories | 2 XP |

**Level progression**

| Level | XP required |
|---|---:|
| Level 1 | 0–999 |
| Level 2 | 1,000–2,999 |
| Level 3 | 3,000–5,999 |
| Level 4 | 6,000–8,999 |
| Level 5 | 9,000–13,999 |
| Level 6 | 14,000+ |

**Language rankings**

Language rankings are based on the code statistics returned by GitHub's repository language API.

They represent the volume of code in repositories, not actual programming proficiency.

<sub>Scoring formula is custom, not an official GitHub ranking. Live XP and level calculations require a GitHub Actions workflow to fetch, calculate and publish the results. The tables above define the scoring rules, not a claim about my current level.</sub>
